# Reading a log on a PC

After this chapter you can read a card image on a personal computer (PC) with the `logring` tool and Python. You can
export its tracks as CSV, MCAP (a container format for robotics logs) or MF4 (Measurement Data Format version 4). You
can also select data by recording or time.
