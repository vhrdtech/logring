# A first log

After this chapter you can mount a ring in firmware, define the drive's tracks, write items and flush them, all on a
simulated card.

The book does not have this chapter yet. Until it does, the drive example shows the code. [`Drive::mount`] mounts the
ring, and [`bench::run`] logs a stretch of the bench. [The format reference](format.md#4-segments-and-flushes) says
what a flush writes.
